## 구현 결과

[UI14 점검](V5_UI_PLAYFLOW_AUDIT_14_REPORT.md)의 1차(UI14-01·02·03)를 구현했다. 아트·음향은 추가하지 않았다.

- **실행 전:** 적 의도/기준 공격과 공격 타입·약점·저항을 전투 본문에 표시한다. 기술별 예상 아래에 총 HP 피해·보호막 흡수·이번 보호, 받을 HP 피해, 실행 후 내 HP를 표시한다. 적 처치/HP 소진/행동턴 한도를 구분한다. 예상 HP는 승리 보상·레벨 회복 전이며 굴림 전/미공개 리롤에서는 수치를 숨긴다.
- **실행 후:** 저장이 성공한 전투 종료의 HP·골드·명예·LV·남은 XP 전후를 보드의 최근 결과 영역에 표시한다. 긴 확정 결과와 직전 AI별 사건/위치/HP/명예/완주는 `AI 결과 보기`에서 읽는다. 별도 계속 버튼이나 필수 모달을 만들지 않았다.
- **진행 관리:** 전투 상단 `모험 메뉴`에서 진행을 보존하고 로비로 나가거나 기존 확인 후 개인만 포기한다. 메뉴 조회·취소·로비·이어하기는 굴림/보관/리롤/기록을 바꾸지 않는다. 연출 중 입력 잠금은 유지한다.
- **관전과 재개:** 개인 종료 사유·남은 인원은 최근 알림과 별도 표시하고 AI 처리 중에도 남긴다. 재개 시 이전 전후값을 추정하지 않고 저장된 현재 상태·AI 기록만 표시한다. 최근 상세는 matchId/revision/generation에 묶인 UI 자료이며 새 경기/복원/재개/실패 등에서 폐기한다.

피해·조합·적 행동·성장·지급·AI·명령·저장 schema는 변경하지 않았다. Preview의 새 필드는 저장 DTO가 아닌 읽기 전용 투영이다. 동일 resolver를 복제 참가자에 실행해 이미 계산된 로그를 읽으며 새 산식을 만들지 않는다. 공동 경기 영구 재화 지급은 기존처럼 0이다.
