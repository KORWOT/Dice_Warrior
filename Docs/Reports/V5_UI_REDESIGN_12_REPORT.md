## 구현

사용자 ZIP 가이드v2의 DICE-01~10을 기존 UI11에 연결했다. 원본 명세·6장 생성시안·연출 HTML을 검토하고 예시의 고정 숫자/결과/장소 그림을 제품 데이터로 복제하지 않았다. 기존 규칙에서 §15의8항목을 확인하여 추가 기획 결정은 필요하지 않았다. 상세 경계와 ZIP 해시는 [PLAN](../Plans/V5_UI_REDESIGN_12_PLAN.md)에 기록했다.

- 이동: 가로 참가자4명 요약·620정사각12장소·고정D6트레이·고정CTA. 확정 결과 저장 후 .75초 회전/.15초 착지, 칸당 .12초 이동과 실제 도착을 표시한다. 출발점 초과 눈은 실제 이동 칸과 구분한다.
- 전투: 실제 물리6면·중복 faceIndex를 보존한 Canvas 입체큐브.1/2/3개를 동일크기로 중앙배치하고 동일슬롯에서 보관/해제한다. 잠금·청록받침·문구로 보관을 표시하고 미보관만 .55초 리롤한다. 이동/전투의 표시가 별도 게임RNG를 사용하지 않는다.
- 공개·실행: 최초 굴림 .75초 동안 결과/조합/예상은 대기. 착지 후 대표면과 라벨/최대3기술을 동시에 공개한다. 기술은 사용①②③→작은 전투장면→실제 피해·보호→생존한 적 행동 순서로 확정 로그를 표시한다.
- 획득: 실제 lap 성공 뒤 추가된 큐브만 합류한다.1→2→3개,3바퀴 장비/최종 시련 유지. 수령완료 문구와 지급 전 안내를 구분한다.
- 보기 설정: 로비/모험 메뉴/전투 상세의 동작 줄이기. App 수명 내 표시 설정이며 경기·계정 저장은 변경하지 않는다. 신규 카메라/RT/물리 판정이나 별도 서버 요청은 없다.
- 기존기능: 실제6면 조회·현재/조회 구분·보상5장비·메뉴복귀·계정·오류/복구·구형 경기 유지. AI 상세는 모험 메뉴에서 확인하며 보드 진행CTA가 스크롤에 밀리지 않는다.

[실제 주요12상태](../UI/V5Redesign/index.html)와 PNG·설명·manifest를 하나의 폴더에 보관했다. 고급 캐릭터/장소 아트·음향(DICE-11)은 가이드의 후속 범위이며 생성시안 수준의 아트가 구현됐다는 뜻은 아니다.
