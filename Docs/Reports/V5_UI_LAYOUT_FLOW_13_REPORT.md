# v5 구성·흐름·배치 개선 REPORT

2026-10-24 · IMPLEMENT · **완료**

## 변경 결과

아트·음향을 제외하고 현재 v5의 핵심 조작과 정보 배치를 개선했다. 입체 주사위·실제 물리 슬롯·저장 후 결과 공개·부분 리롤·기술/적 행동 순서는 유지한다. 추가 기획 결정이 필요한 게임 규칙 변경은 없다.

- **로비:** 다음 출전 요약과 보조 선택을 구분하고 새 모험/이어하기를 하단 고정 버튼으로 표시한다. 진행 중이면 이어하기가 우선이다. 모험가·출전·능력치·계정·새 게임은 기존 경로로 접근한다. 주사위 6면과 설정·복구는 상단 도구이며 백업·동작 줄이기는 설정·복구에서 연다.
- **전투:** 적/내 상태→주사위 트레이→기술별 예상→행동 버튼 순서로 배치한다. 트레이 내부 큐브 크기·위치는 유지하고, 예상 기술을 최대3행으로 나눠 실행 순서·사용 슬롯·피해 타입·실제 피해/보호를 표시한다. 굴림 전/회전 중에는 결과를 공개하지 않는다.
- **정보·관리:** 정보창은 내용 길이에 맞춰 배치한다. 현재 능력치와 모험 메뉴로 이동한 후 원래 정보창으로 복귀한다. 포기 취소는 현재 전투를 보존한다. 백업 복원 성공은 이전 정보창과 복귀 참조를 비우고 로비로 돌아간다.
- **사건·보상·결과:** 사건 제목 반복과 보상 설명의 같은 상세 중복을 제거했다. 비용·조건·지급 전후·장비 비교를 유지한다. 결과는 참가자별로 구분하고 로비 복귀를 하단에 고정한다.

로비의 선택은 다음 새 모험용으로 즉시 저장한다. 사건·보상 후보는 기존처럼 누르면 확정하며 새 확인 단계를 추가하지 않았다. 게임 명령·RNG·저장 DTO·AI·재화/정산·서버는 변경하지 않았다.
