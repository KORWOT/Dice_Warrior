## 확정 게임 루프

Android 세로 화면, 모험가 1명, 적 1명. 로비 준비 → 이동 D6 → 착지 사건 → 한 바퀴 보상 → 다음 지역 → 지역 3 보상 → 최종 보스 → 결과 정산 → 영구 성장.
전투는 검·지팡이·불·방패 기호 주사위 1개로 시작한다. 지역 1·2 완주 보상으로 2·3개가 된다.
6면 기호 주사위의 분포를 고르고 교체하며 장비 3칸(무기·방어구·장신구)을 준비한다.
카드 소유·학습·와일드 카드·6D6 족보·운명력·재굴림·분기 지도·전투 스킬 선택은 제거한다.

## 전투 계약

전체 눈의 순서 무관 멀티셋과 정확히 일치하는 조합 기술 **한 개**를 발동한다.
부분 조합을 찾지 않는다. 불일치하면 주사위 순서대로 모든 기본기를 실행하며 같은 눈도 각각 한 번이다.
기본기와 조합기는 같은 피해/보호막 계산을 쓴다. 장비는 기술 태그에 맞는 보너스만 준다.
수호는 보호막 기술의 효율이며 상시 피해 감소가 아니다.

- D1: 적 사망 이후 계획된 기본기는 `enemy-defeated`로 생략 기록. 계획·적용·생략을 구분한다. 죽은 적은 반격하지 않는다.
- D2: 적 보호막은 플레이어 기술 묶음 전체에서 차감하고 남은 양은 묶음 끝에 만료한다.
- 살아 있는 적은 예고된 공격/강공격/방어 중 하나를 한 번 실행한다. 플레이어 보호막은 반격/턴 종료 뒤 만료한다.
- 면 결과·기술 ID·효과·적 의도·턴 전후 HP/보호막을 저장한다. UI 재표시·재개는 확정 로그만 읽는다.

## 캠페인 계약

지역당 12칸: 시작 0, 사건 1..11. 이동 D6 1개, 착지 타일만 처리한다.
`위치 + 눈 >= 12`이면 위치 0의 완주 보상 대기로 전환하며 초과 이동을 버린다. 일반 타일 사건은 없다.
지역 보드는 시드와 지역 번호에서 파생한 별도 RNG로 한 번 생성하고 저장한다. 전투 RNG와 독립적이다.
각 보드에 전투·이벤트·보물·상점·휴식이 모두 존재한다.
완주 보상은 `runId:region:lap` ID로 한 번 확정한다. 지역 3의 보상도 보스 **진입 전** 받는다.

## 성장·선택·시험값

다음 수치는 밸런스 확정이 아닌 MVP 시험값이며 설정 SO에서 새 런에 반영한다.

| 항목 | 첫 시험 |
|---|---|
| 시작 능력 | HP 60, 위력 5, 수호 4 |
| 기본기 | 검: 피해 위력+2, 지팡이: 위력+1, 불: 위력+3, 방패: 보호막 수호+3 |
| 2눈 조합 | 검+지팡이 검기, 지팡이+불 화염탄, 검+방패 수호 베기 |
| 3눈 조합 | 검+지팡이+불 화염 검기, 검+방패+방패 성채 베기 |
| 일반 전투 | 지역별 적 HP·공격 증가, 승리 XP 5/골드 12 |
| 레벨 | 필요 XP=현재 레벨×8, 상승 시 최대 HP+6/현재 HP+6/위력+1/수호+1 |
| 완주 | 골드 15, XP 5, HP 12 회복; 지역1·2 주사위 추가, 지역3 장비 선택 |
| 영구 정산 | 완료 지역×10 + 최종 승리 20, 런당 한 번 |
| 영구 성장 | 다음 단계 비용 20×(단계+1), 다음 새 런 최대 HP+5 |

로비에서 시작 주사위 종류와 무기를 선택한다. MVP 준비물은 공통 해금된 세트이며 영구 보유품 수집은 보류한다.
이벤트는 HP 대가와 골드/XP 중 선택, 휴식은 회복/훈련 선택, 보물은 장비/주사위 교체 선택, 상점은 골드를 쓰는 회복/장비/주사위 교체를 제공한다.
교체는 장비 슬롯 또는 주사위 슬롯을 명시하고 거절/뒤로 가기를 제공한다.
선택 후보를 저장하며 화면 재진입에 재추첨하지 않는다. 전투 중 교체는 불가하다.
런 XP·장비·골드는 런 내부 값이다. 영구 재화와 성장 단계만 다음 런으로 이어진다.

## 실행·저장·화면

`SymbolLoop`가 유일한 게임 기능이다. 순수 도메인 → 세션/저장 → 화면으로 의존한다.
설정은 런 시작에 복사한다. 세션 명령은 후보 복제 → 토큰/규칙 검사 → 저장 성공 → 공개 순서다.
요청 ID/입력/revision/복구 세대로 중복·오래된 입력을 구분한다. 재시도는 같은 요청을 사용한다.
체크섬 파일과 마지막 정상 백업을 사용하고 손상 시 자동 초기화하지 않는다. 복구는 백업 확인 후 명시 입력으로 실행하고 세대를 올린다.
저장 경로는 `Application.persistentDataPath/symbol-loop-v1/player.json`. v1 경로를 열지 않는다.
Title.unity 하나에서 로비/보드/전투/보상/결과를 전환한다. 고정 UI는 Editor에서 작성한 프리팹, 반복 타일·선택지는 작성된 슬롯을 바인딩한다.
공통 uGUI 기반과 폰트·외부 플러그인을 유지한다. 장치 실플레이·밸런스·최종 아트는 별도 확인 대상이다.

## 보드·주사위·스킬 표시 계약 (2026-10-21)

사각 둘레의 12칸에서 전사 말이 시계 방향으로 이동한다. 숫자 D6의 면이 회전·감속해 확정 눈을 보여준 뒤 말이 한 칸씩 튀며 이동한다. 출발점 통과 시 0번에 멈추고 초과 칸을 버린다. 사건 화면은 착지 후 열린다.

전투에서는 보유한 1~3개의 주사위가 실제 여섯 기호 면을 가진 입체 Canvas 메시로 회전한다. 정지 면은 저장된 결과다. 전체 조합 안내 후 조합 스킬 1개, 또는 기본기를 눈 순서대로 표시한다. 검격/마법/화염/방어는 각각 기호·색·이동/충격 효과를 가지며 스킬 이름, 피해/보호막, 체력 바를 함께 갱신한다. 처치 뒤 생략된 스킬과 없는 반격은 표시하지 않는다. 적용된 플레이어 기술 뒤 기록된 적 공격/방어를 표시한다.

연출은 저장 성공 후 전후 상태와 턴 로그를 소비한다. 게임 RNG나 피해 계산은 재실행하지 않는다. 재생 중 명령 입력을 잠그고, 앱 비활성/백그라운드/화면 닫기/다시 불러오기는 최종 확정 상태로 복귀한다. 연출 중 종료해도 이미 저장된 결과를 다시 지급하지 않는다.

코드로 그린 벡터 아트와 입체 투영 방식이며 Rigidbody 물리 주사위·최종 캐릭터 아트·음향은 이번 범위에 포함하지 않는다. 세로 720×1280 기준 레이아웃을 가용 safe area에 균일 축소/확대한다. 구현 및 실제 검증 상태는 [화면 PLAN](Plans/SYMBOL_LOOP_PRESENTATION_PLAN.md) / [화면 REPORT](Reports/SYMBOL_LOOP_PRESENTATION_REPORT.md)를 따른다.
