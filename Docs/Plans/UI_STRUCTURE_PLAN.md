## Shared UI interface (owner C)
Namespace FateDice, existing FateDice.SharedUI assembly (uGUI only).
- UIData: abstract runtime class; no callbacks in shared base.
- BaseUI : MonoBehaviour: public CanvasGroup group; public bool IsOpen; public Type DataType; public UIManager Manager {get; private set;}; internal attachment/show/rebind/close. Show validates type, initializes once, binds before activation. Failed binding leaves manager consistent. Close cancels StopAllCoroutines and calls OnUnbind once, clears data, deactivates. Close never runs a game reward.
- BaseUI<TData> : BaseUI where TData : UIData: protected abstract void OnBind(TData data); protected virtual void OnInitialize(); protected virtual void OnUnbind(). Retain typed data only while open. Shared manager owns transitions.
- UIRoot : MonoBehaviour: public Canvas canvas; public RectTransform safeArea, screenLayer, popupLayer, overlayLayer, cacheLayer; public CanvasGroup inputGroup; public UnityEngine.UI.Image popupBlocker; public void ApplySafeArea(). Background blocker covers safe area and is active only when popups exist. Cache is inactive, screens/popups are stretched in their authored root anchors; overlay has no blocking graphic by default.
- UIManager : MonoBehaviour: public UIRoot root; public BaseUI[] prefabs; public UIRoot Root => root; public BaseUI ActiveScreen; public IReadOnlyList<BaseUI> Popups; public int CachedCount; public T Show<T>(UIData data) where T:BaseUI; public T ShowPopup<T>(UIData data) where T:BaseUI; public bool CloseTopPopup(); public void CloseAll(); public void SetInputLocked(bool locked); public bool TryGetCached<T>(out T view). Unique concrete type registrations validated. One instance per concrete type. Show same screen rebinds without close; changing screen closes old. Different popup types may stack, same popup rebinds and comes top. Only top popup interactable, underlying screen/non-top popups blocked; blocker must be immediately below top popup. Restore prior selected UI object on pop when still usable; clear stale selection on closing/changing screens. Root inputGroup exposes lock state (legacy GUI oracle). Global lock may not be bypassed by popup manipulation. No InputSystem dependency in SharedUI (controller handles Escape).
