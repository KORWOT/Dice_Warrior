# v5 구성·흐름·배치 · 주요 화면

2026-10-24 · 아트·음향 제외. [갤러리](index.html)의12장과 PNG·manifest를 같은 폴더로 보관합니다. 검증 결과는 [REPORT](../../Reports/V5_UI_LAYOUT_FLOW_13_REPORT.md), 계약은 [PLAN](../../Plans/V5_UI_LAYOUT_FLOW_13_PLAN.md)을 참고하세요.

## 진행 흐름

로비 → 모험가/출전 선택 → 시작 또는 이어하기 → 보드 이동 → 사건 선택 → 전투(굴림 → 보관/리롤 → 기술 실행) → 완주 보상 → 최종 시련 → 결과 → 로비.

- 모험가·출전 선택은 다음 새 모험용으로 즉시 저장하며 현재 경기에 소급하지 않습니다.
- 이어하기는 저장된 단계로 복귀합니다. 새 모험 교체는 기존 확인을 거칩니다.
- 사건·완주 보상은 후보를 누르면 즉시 확정합니다. 중간 확인 단계는 추가하지 않았습니다.
- 로비의 설정·복구에서 백업과 동작 줄이기를 봅니다. 전투 정보에서 모험 메뉴로 이동하면 진행 유지/포기를 구분할 수 있습니다.
- 정보 → 능력치/관리 → 돌아가기는 원래 조회 상태로 복귀합니다. 포기 취소는 현재 전투를 유지하고, 백업 복원 성공은 이전 정보창을 닫고 로비로 돌아갑니다.

## 화면별 설명

1. **새 모험 준비 · 고정 시작 버튼** — 출전 요약과 보조 선택을 위에 모으고, 새 모험 시작은 하단에 고정합니다. 주사위 6면과 설정·복구는 오른쪽 위에서 엽니다.
2. **진행 보존 · 이어하기 우선** — 진행 중인 경기가 있으면 이어하기가 고정 버튼이 됩니다. 새 모험은 보조 카드이며 기존 교체 확인을 거칩니다.
3. **다음 모험가 선택** — 선택은 다음 새 모험용으로 즉시 저장합니다. 진행 중인 경기의 모험가는 바뀌지 않습니다.
4. **주사위·무기 출전 구성** — 주사위·무기는 같은 화면에서 연속 변경할 수 있습니다. 목록은 스크롤하며 돌아가기는 저장 취소가 아닙니다.
5. **현재 위치와 고정 이동 행동** — 현재 위치와 네 참가자의 요약을 확인한 뒤 하단의 이동 주사위를 굴립니다. 기존 이동 판정과 연출을 유지합니다.
6. **사건 · 비용과 보상 비교** — 제목을 반복하던 설명을 줄이고 실제 비용·조건·보상을 비교합니다. 후보를 누르면 기존 방식대로 즉시 확정합니다.
7. **전투 · 첫 굴림 준비** — 적·내 상태, 주사위 트레이, 발동 예상, 행동 버튼 순서입니다. 첫 굴림 전에는 결과와 예상 기술을 공개하지 않습니다.
8. **보관 · 기술별 예상 결과** — 예상 기술을 실행 순서별 행으로 구분합니다. 각 행의 ①②③은 실제 사용 주사위 슬롯입니다. 보관·리롤·실행 규칙은 같습니다.
9. **전투 정보 · 조회와 관리 분리** — 전투 정보는 읽기 전용입니다. 내용 길이에 맞춰 묶음을 배치하고, 능력치와 모험 관리로 이동할 수 있습니다.
10. **모험 관리 · 진행 보존과 포기 구분** — 로비로 진행을 보존하는 행동과 참가자를 포기하는 행동을 구분합니다. 포기는 기존 확인을 거치며 취소 후 돌아가면 원래 정보창을 복원합니다.
11. **완주 보상 · 실제 교체와 지급 비교** — 실제 지급 전후와 장비 교체 비교를 한 번씩 표시합니다. 장비 후보 5개는 스크롤로 모두 볼 수 있고 선택 즉시 수령 후 최종 시련으로 이어집니다.
12. **결과 · 순위와 고정 로비 복귀** — 순위별 내용을 묶고 로비 복귀를 하단에 고정합니다. 완료 결과는 보존하며 새 모험 시작은 로비에서 진행합니다.

## 촬영 범위

실제 authored UI를720×1280 Editor PreviewScene에 표시했습니다. 전투·보상은 유효한 격리 fixture 후 실제 명령을 사용했으며, 결과 화면은 실제 포기/AI 진행으로 완료한 시험 경기입니다. 게임 규칙·계정 성장·재화·실제 저장/서버를 바꾸지 않습니다. 실기기 안전영역/물리 터치/GPU/시스템 확대는 NOT_RUN입니다. 390×844/360×640 모의 안전영역 근거는 REPORT와 검증 기록을 참고하세요.
