# v5 전투 판단·결과 피드백 주요 화면

2026-10-25 · UI15 · 아트·음향 제외

[index.html](index.html)을 열면 이 폴더의 주요8장과 설명을 함께 볼 수 있다. 폴더를 통째로 복사해도 갤러리는 외부 파일 없이 열린다. 기존 전체 화면 이력은 ../V5Layout에 유지하며 이번에는 바뀐 핵심 화면만 포함했다.

## 흐름과 읽는 법

전투 준비 → 굴림/보관/리롤 → 피해·HP 예상 → 실행 → 승리·성장 요약 → AI 결과 조회 → 계속 이동 또는 진행 보존 후 로비 → 개인 종료/AI 관전 → 최종 결과.

실행 전 HP 예상은 **승리 보상·레벨 회복 전**이다. 승리 후 최근 결과 HP는 **보상·성장 적용 후 확정값**이다. 재개하면 없는 과거 전후값을 추정하지 않고 현재 저장 상태와 남아 있는 AI 기록만 표시한다.

## 촬영·검증 범위

- 실제 authored CompetitionScreen.prefab, Editor PreviewScene,720×1280. 전투 주사위3개/특정 물리면/적 HP 및 레벨업 직전 XP는 격리된 유효 fixture다. 실행/승리 보상/AI 처리는 실제 게임 명령과 저장 경로를 사용했다.
- [manifest.json](manifest.json)은 화면마다 촬영 조건·실제로 보이는 텍스트/버튼을 기록한다. [validation.json](validation.json)은 이번 실행 결과와 사진 해시를 기록한다.
- Validation의8장은390×844/360×640와3%/4% 모의 안전영역을 사용한 진단 사진이며 주요 갤러리에 섞지 않았다.
- 실제 사용자 저장·HTTP/Firebase는 사용하지 않았다. 실기기 터치·GPU·시스템 글자 확대·장시간 사용자 관찰은 미실행이다.
- 게임 규칙·저장 schema·영구 보상 정책을 변경하지 않았다. AI 자동 진행·새 영구 이력·아트·음향·진동은 포함하지 않는다.
