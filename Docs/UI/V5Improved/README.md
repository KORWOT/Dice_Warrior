# Dice Warrior · 개선 UI 화면 안내

2026-10-24 · 실제 Unity 프리팹 캡처 12장 · 720×1280

로비 → 출전 준비 → 보드 이동 → 사건 선택 → 전투(굴림 → 보관/리롤 → 기술 실행) → AI 행동 → 내 차례 → 완주 보상 → 최종 시련 → 결과.

조회는 경기 상태를 바꾸지 않습니다. `로비로 · 진행 유지`는 이어하기를 보존하고, `내 모험 포기`와 `새 모험 시작`은 별도 확인을 거칩니다. 사진의 일부 목록은 실제 화면에서 세로로 스크롤합니다.

검증: 순수 .NET 207/207, Unity 개선 UI 18/18, 기존 화면 25/25, 별도 경계 확인 23항목 통과. 실제 Android 장치·물리 터치 dp·OS 뒤로 제스처는 미실행입니다. 서버는 격리 메모리 응답을 사용하며 Firebase와 실제 계정/저장을 사용하지 않았습니다.

캡처의 전투는 합법 격리 상태/물리면 조합입니다. 완주 보상과 결과는 격리 시작 프로필에서 실제 명령으로 진행했습니다. 각 근거는 `manifest.json`의 setup에 남겼습니다. 기존 개선 전 사진 묶음은 보존했습니다.

## 01-lobby · 다음 새 모험과 저장 경기 구분

모험가·주사위·무기를 한곳에서 확인합니다. 저장 경기가 있으면 이어하기와 새 모험 교체가 구분됩니다.

![로비](01-lobby.png)

## 02-adventurers · 선택 즉시 저장

선택된 모험가에 텍스트 표시를 더했습니다. 연속 선택할 수 있고 다음 새 모험에만 반영됩니다.

![모험가 선택](02-adventurers.png)

## 03-loadout · 슬롯별 출전 구성

시작 주사위와 시작 무기를 구분하고 실제 6면·장비 효과를 설명합니다. 아래로 스크롤하면 모든 후보를 볼 수 있습니다.

![출전 구성](03-loadout.png)

## 04-board · 내 위치와 진행 목표

나/AI·참가자 번호·순위·완주 목표를 보여 줍니다. 사건 해결 뒤에는 직전 AI 행동과 확정 변화량을 표시합니다.

![공동 모험 보드](04-board.png)

## 05-encounter · 비용과 보상 비교

HP 소모와 최소 HP 조건을 구분하고 현재 자원, 실제 행운 골드, 경험치·명예·적 상성을 보여 줍니다.

![도착 사건](05-encounter.png)

## 06-combat · 주사위와 기술을 직접 연결

①②③은 주사위 슬롯입니다. 각 기술의 사용 슬롯·예상 피해·보호를 연결하며 굴림과 보관 영역을 분리합니다.

![굴림과 보관·기술 예상](06-combat.png)

## 07-dice-net · 이번 결과와 조회 면 구분

1~6번은 한 주사위의 물리면입니다. 이번 굴림과 조회 중 표시를 각각 유지하고 실제 중복 면도 별도로 보여 줍니다.

![주사위 6면 조회](07-dice-net.png)

## 08-combat-info · 전투 정보와 모험 메뉴

전체 발동 예상·남은 횟수·20행동턴·보호 소멸 규칙을 설명합니다. 진행 유지와 포기는 별도 메뉴에 있습니다.

![전투 정보와 모험 메뉴](08-combat-info.png)

## 09-stats · 조회 기준과 활성 탭

다음 모험/현재 경기를 명시하고 능력치·주사위/스킬·속성·태그·효과 출처를 나눕니다. 닫으면 원래 맥락으로 돌아갑니다.

![출전 능력치](09-stats.png)

## 10-account · 승인 전후와 실패 이유

보유 재화·성장 및 구매 후 예상값을 표시합니다. 승인 대기·성공·부족·실패·구형 기록 보류를 구분합니다.

![계정과 영구 성장](10-account.png)

## 11-reward · 선택 즉시 수령

아직 지급하지 않은 보상을 명시하고 실제 골드·레벨·HP 전후를 비교합니다. 세 번째 보상은 장비5개와 조회/메뉴가 독립되어 있습니다.

![완주 보상과 선택 확정](11-reward.png)
