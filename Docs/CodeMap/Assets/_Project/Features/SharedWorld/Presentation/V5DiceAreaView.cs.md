# V5DiceAreaView.cs

- 역할: v5 인간 전투의 고정 슬롯 큐브 트레이, 작은 전투 장면, HP/적 의도, 기술 예상, 하단 리롤/실행과 정보 진입을 authored 참조로 표시한다.
- 핵심 동작: 원래 slotIndex/instanceId를 슬롯과 콜백에 유지한다. 보관 전후 부모는 rollZone 하나이며 SlotPosition(slot,count)으로1·2개는 중앙,3개는 같은 간격으로 배치한다. holdZone과 기존2D faces는 직렬화 호환용으로 보존하되 숨긴다. AwaitRoll도 실제 보유 큐브를 결과 없는 정지 상태로 표시하고 footer의 첫 굴림/조회만 허용한다. Selection은 CanHold/남은 리롤/미보관 여부로 버튼을 제어하고 실행은 꽝/전부 보관에서도 허용한다. 제한/실패 문구는 authored feedbackScroll 안의 notice에 표시한다.
- 입출력: Bind(state,dispatch,showDice,showCombat,message), Snap(state), Play(kind,before,after), Unbind. 출력은 Text/Image/CommonButtonView/V5FaceGraphic의 위치·배율·색·활성 상태이며 IsAnimating/DiceRolling은 검증용 표시 상태다.
- 예상/연출: CompetitionV5Skills.PlanSteps/Preview의 동일 계획으로 최대3개 기술 전체·사용 slot·조합 크기를 연결한다. 슬롯 라벨은 지속 번호/주사위 종류/결과/보관/기술번호를 표시한다. 모두 꽝은 발동 기술 없음과 적 행동 안내다. 최초 굴림 .75초/부분 리롤 .55초 동안 대상 큐브만 Pose를 변경하고 결과 이름·모든 기술 그룹·예상을 대기로 바꾼다. 보관 큐브는 기존 면·자세·좌표를 유지하며 리롤 잔여는 확정 after를 표시한다. 착지에서 면/라벨/예상을 함께 공개한 뒤 .15초 읽기 시간을 둔다. 보관/해제 .12초는 동일 슬롯의 받침·잠금 강조만 바꾼다. ReducedMotion은 회전/도약을 생략하며 최종 결과와 판정은 같다.
- 기술 장면: 신규 authored hero/enemy/effect Glyph와 stageAction/impact는 확정 SkillLog 순서의 기술·사용 슬롯·피해 타입/보호 효과를 연결한다. skipped는 처치 후 생략으로 표시하며 새 발동 효과를 만들지 않는다. log.retaliation일 때만 적 행동을 재생한다. EnemyActing/VisibleSkill은 표시 상태이며 규칙/RNG/저장을 실행하지 않는다.
- F02 실행 건강 표시: execute는 before로 Snap하여 최종 HP가 먼저 노출되지 않는다. SetHealth가 매 단계 HP 텍스트·HP바·적 보호·아군 현재 보호를 함께 갱신한다. 기술마다 저장 SkillLog의 HP/보호와 누적 생성 보호를 표시하고, 적 행동 종료 시 저장 log.playerHpAfter/적 방어 결과 및 현재 보호0(턴 초기화)를 표시한다. 마지막 after Snap에서 전투 보상/레벨 회복을 포함한 최종 확정 상태로 복귀한다. 선택 대기 중 현재 보호는 항상0으로 명시한다.
- 사용하는 대상: v5 Content/Dice/Skills DTO, 기존 TurnLog/Intent, CommonButtonView, V5DieGraphic, LoopGlyphGraphic, uGUI. 큐브는 실제 Faces의6개 물리면과 result.faceIndex를 바인딩하고 스킬/피해 타입과 별개로 읽는다.
- 사용하는 쪽·관계 근거: CompetitionScreen.Bind, CompetitionPlayback.Play/Snap, CompetitionAuthoring.BuildV5Area, CompetitionCombatUiAuthoring.Upgrade, CompetitionV5FlowTests/CompetitionCombatUiTests가 직접 호출/참조한다. DieLabel/Marker는 Net이 같은 주사위 식별을 표시할 때 재사용한다.
- 상태/수명: App가 저장 후 코루틴과 전체 입력 잠금을 소유한다. Snap은 Cube 결과·회전/강조·고정 슬롯·전투 장면을 확정 상태로 복구한다. footer는 화면 safe area 하단에 독립 고정하며 본문과 같은 배율을 쓴다. ReducedMotion은 App의 로컬 보기 설정에서 전달되며 경기 저장에 넣지 않는다. Unbind는 콜백을 제거한다.
- 검수 주의: runtime GameObject 생성 없음. 필수 authored3슬롯/3큐브/전투장면/feedbackScroll이 필요하다. 슬롯200×248·cube160×180·352높이 트레이와 작은 메시 투영/도약이 경계 전제다.20번째 행동·보호 초기화·살아 있는 적만 반격·리롤/보관제한은 실제 규칙을 안내한다. 실제 터치/취소/여러비율·안전영역·투영 메시/그림자/잠금 프레임 검증은 메인의 Unity 실행 결과를 따른다. 설계단위를 실제기기dp로 주장하지 않는다.
