# CostEstimatorTests.cs

- 역할: 가상 Firestore 작업과 단위별 비용/무료 할당량 계산의 회귀 검사.
- 핵심 검증: SQL999/SQLite CAS20을 넣어도 논리 읽기는 불변, 응답 유실 후 승인 쓰기 유지, 같은 요청/이미 제출된 런 중복의 다른 읽기·쓰기, 조회 실패에도 읽기, 권한 전 오류와 검증 거절 분리.
- 손계산:100DAU×일2런×30일의36000읽기/42000쓰기/12000요청 및 CPU·메모리 요금; 일50000/60000조회 무료 경계; 서울 Cloud Run CPU 크레딧의 Tier1 환산;1GiB 저장 무료;한국 전송10240GiB 구간과 Firestore 무료 전송 오적용 방지.
- 추가 검증: retentionDays의 일별 보관 평균과 삭제량, 최소/기준/최악 순서,0/상한 DAU의 유한 decimal 결과와 입력 미변경, 미지원 지역·잘못된 범위, 잘못된 요금 단위·음수·NaN·중복·누락·에디션, 누락 요율의 null 합계, 파일 요율 변경이 계산에 반영됨.
- 입출력/사용: NUnit·CostEstimator·FirebaseOperationModel·PricingCatalog; 기본 요금 JSON과 임시 요금 fixture만 사용한다. Unity/실제 서버 DB/Firebase/클라우드 청구에 접근하지 않는다.
- 관계 근거: 각 테스트에서 실제 공개 계산 API를 호출하고 문서 수·바이트·금액을 직접 비교한다. 사용자 프로필과 게임 저장에는 의존하지 않는다.
- 상태/수명: 테스트별 새 DTO/임시 파일 생성 후 해당 파일만 정리. 전역 요금 변경 없음.
- 검수 주의: 오프라인 모델 검증이며 실서비스 비용이나 부하 성능의 PASS 근거가 아니다. 최신 실행 결과는 M4 REPORT/Evidence를 따른다.
